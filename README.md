# Онлайн-доска

Доска для совместного рисования в реальном времени. Открываете сайт, получаете новую доску со своей ссылкой, отправляете ссылку кому угодно и рисуете вместе. Регистрация не нужна.

Умеет: карандаш и маркер с ползунком толщины (с Shift — прямая линия), линии, стрелки, прямоугольники, эллипсы, текст, стикеры, картинки (кнопка, Ctrl+V или перетаскивание файла; размер меняется за уголок), ластик, выделение и перемещение, отмену и повтор, масштаб, перемещение доски правой кнопкой мыши, живые курсоры и линии других участников прямо во время рисования, экспорт в PNG, телефоны. Каждый участник может выбрать себе оформление (10 палитр или свою: фон + акцент) — выбор хранится только в его браузере.

## Запуск у себя

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000 — вас перенаправит на новую доску вида `/b/xxxxxxxx`.

Настройки через переменные окружения:

- `PORT` — порт (по умолчанию 3000)
- `DATA_DIR` — папка, где хранятся доски (по умолчанию `./data`)

## Где работает

**https://online-board.risuem.workers.dev** — Cloudflare Workers. Доски и картинки хранятся в Durable Objects (SQLite), по одному объекту на доску.

## Владелец сайта

- **Панель владельца:** `/admin`. Вход по паролю. Первый пароль задаётся по одноразовой ссылке `/admin#setup=<SETUP_TOKEN>`, где `SETUP_TOKEN` — секрет Worker'а (`npx wrangler secret put SETUP_TOKEN`).
- **В панели:** создание досок, список всех досок (онлайн, число рисунков), переименование, режим «все рисуют / только смотрят», удаление, настройка «кто создаёт доски» (только владелец или любой посетитель), смена пароля.
- **На доске у владельца (и у создателя доски) есть кнопка «Управление»:** название, доступ по ссылке, список людей онлайн (разрешить/запретить рисовать, выгнать, заблокировать), разблокировка, очистка и удаление доски.
- **Права проверяются на сервере:** зритель не может рисовать, загружать картинки или очищать доску, даже если подделает запрос. Блокировка привязана к браузеру человека, а не к IP: на одном Wi-Fi может сидеть целый класс.
- Пароль хранится как PBKDF2-хеш. После 5 неверных попыток вход блокируется на 10 минут. Сессия хранится в HttpOnly-cookie 30 дней.

`server.js` — упрощённый вариант для своего сервера: без владельца и ролей.

## Выложить в интернет

### Cloudflare Workers (бесплатно)

Нужен API-токен Cloudflare по шаблону «Edit Cloudflare Workers».

```bash
npm install
```

```bash
CLOUDFLARE_API_TOKEN=<токен> npx wrangler deploy
```

Страница встраивается в код Worker'а как текст (`[[rules]]` в `wrangler.toml`), отдельной загрузки статических файлов нет. Локально: `npm run dev` → http://localhost:8787.

### Свой сервер на Node.js

Подойдёт любой хостинг, который запускает Node.js и поддерживает WebSocket: Render, Railway, Fly.io, свой VPS.

**Render.com:** New → Web Service → подключите репозиторий. Build command: `npm install`, start command: `npm start`. Чтобы доски не пропадали при перезапуске, добавьте Disk с путём `/data` и переменную `DATA_DIR=/data`.

**Docker / VPS:**

```bash
docker build -t online-board .
docker run -d -p 80:3000 -v board-data:/data --restart unless-stopped online-board
```

## Как устроено

- `src/worker.js` + `wrangler.toml` — версия для Cloudflare Workers.
- `server.js` — HTTP-сервер для страницы и WebSocket `/ws` для синхронизации. Каждая доска хранится в `DATA_DIR/<id>.json`.
- `public/index.html` — вся клиентская часть, без сборки.
